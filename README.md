# VA Polo GroupMe Bot

A bot that automatically posts daily horse care responsibilities to a GroupMe chat.

## What It Does

- **bootcamp.py** - Posts tomorrow's bootcamp helpers
- **feeding.py** - Posts tomorrow's feeders  
- **mucking.py** - Posts today's muckers

Each script pulls assignment data from Google Sheets and posts them to GroupMe.

## Cron Jobs

Cron jobs are triggered from [https://console.cron-job.org/dashboard](https://console.cron-job.org/dashboard)
